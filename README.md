# 🍕 Pizza Sales Analytics Dashboard

## Overview
This project analyzes pizza sales data using SQL, Python, Pandas, and Streamlit.

## Tools Used
- SQL
- Python
- Pandas
- Plotly
- Streamlit

## Features
- Revenue Analysis
- Top Selling Pizzas
- Revenue by Category
- Revenue by Size
- Monthly Revenue Trend
- Peak Ordering Hours
- Interactive Dashboard Filters

## Dataset
- Orders
- Order Details
- Pizzas
- Pizza Types

## KPIs
- Total Revenue
- Total Orders
- Total Pizzas Sold
- Average Order Value
